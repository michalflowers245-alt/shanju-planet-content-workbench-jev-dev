# 抖音完整发布文案改造

## 本轮实现

- 登录态继续由工作台专用 Chrome 提供；读取详情时逐篇核对目标视频 ID，ID 不一致拒绝保存。
- 扩大详情页结构化状态的读取范围，并补读 HTML/video 字幕轨；发布文案、字幕和已有 ASR 字段保持分开，不拼接伪造成“口播原文”。
- 详情结构中与目标 ID 一致的结构化发布文案标记为 `COMPLETE`；页面可见文字、搜索卡片文案或仅字幕仍为 `PARTIAL`。`COMPLETE` 只代表发布文案完整，不代表完整视频媒体或口播转写。
- JEV 判为 A 的抖音候选每批最多 500 条进入串行详情队列，逐篇读取；登录/安全验证、浏览器缺失或平台限制会暂停剩余队列。用户在平台处理后，重新读取成功会恢复队列。
- 详情库最多返回 500 条，前端增加完整发布文案标记，并在有 ASR 记录时独立展示其文本、模型和状态。
- 接入 macOS 26+ 的 Apple SpeechAnalyzer 简体中文本机识别。若本机中文模型已安装，JEV 判 A 的抖音候选会在详情 ID 核验后，自动尝试从工作台专用 Chrome 当前登录会话读取 allowlist 中可访问的单文件媒体，在本机临时转成单声道 WAV 并离线识别；原媒体/WAV 自动删除，只保存文本、来源标记、哈希、大小与时长。
- 本机转写单条限制 500MB、15 分钟；依赖本机 `swiftc`、`ffmpeg`、`ffprobe`。自动模式不会静默下载中文模型；若模型未就绪，详情卡会显示状态，可用本机导入路径按用户确认初始化。
- UI 分开标记登录态媒体 ASR 与用户导入 ASR；两者均不等同于平台字幕或发布文案。机器转写需人工核对。媒体不可访问、播放列表、登录墙、安全验证或平台限制时不会绕过机制，可改用有权处理的本机文件。
- 不导出 Cookie/Token，不保存签名媒体 URL 或视频归档，不绕过登录、安全验证或限流。

## 尚未验证与边界

- 本轮没有替用户登录，也没有读取现有平台登录资料。新版工作台必须由用户在它自己的专用 Chrome 中扫码登录后，真实媒体访问能力才能做在线验收。
- 本机合成的简体中文测试音频已验证 SpeechAnalyzer；自动化测试覆盖身份绑定、登录态流式媒体模拟、本机 ASR 和临时文件删除。真实抖音发布视频的实际媒体 CDN 与人工听校尚未完成验收。
- 自动转写覆盖本轮搜索池中 JEV 判 A 的最多 500 条候选，不代表账号/平台全量。机器识别稿不能保证零漏字；媒体不可访问、受保护、已删除、播放列表或平台限制时会保留失败状态。
- 平台本轮搜索结果受关键词、可见范围、排序、配额和风控影响；500 是单批读取上限，不是抖音全站内容保证。
